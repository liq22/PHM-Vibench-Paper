# 02 Challenges & Scientific Questions

## 核心难点（工程 + 科学）

### (1) 可控性与保真度同时满足
- 可控：你设定的 y/s(t)/λ/Δf/p_clip 必须“测得出来”
- 保真：生成样本必须有真实纹理（宽带、重尾、非平稳）

### (2) 变速工况：Hz 域失效
- 特征频率随转速漂移
- 需要 order tracking 或动态容差带宽

### (3) 工程约束：PHM-Vibench 的 config-first
- 新组件必须可注册、可复现、可评测
- 不能把主框架改坏

## 科学问题（写论文的 4 个问题）

### Q1：解耦生成是否真能“又可控又逼真”？
对比：Skeleton-only / Flow-only / DSSF  
指标：可控表（ECS/RDS/SAS）+ 保真表（PCS/FVD）

### Q2：可审计生成是否可行？
命题：**每条样本都可被反证**  
证据：Table 1（Set → Measure → Error）

### Q3：生成即域随机化是否能提升跨域泛化？
证据：跨数据集/跨工况/跨传感器测试，Table 3

### Q4：变速下仍能保持物理一致性吗？
证据：order-domain PCS 或动态容差 PCS

## 批判 → 改进 → 再批判（落到“怎么做实验”）

### 批判：只报 accuracy 没意义
- 生成样本可能提升某个数据集，却在真实现场翻车

**改进**：主结果必须包含“可证伪表 + 跨域表 + 小样本表”。

### 再批判：跨域表也可能被挑数据集
**改进**：明确“目标域 knobs”来自可观测工况（转速范围、SNR、量化位数等），并记录来源（meta）。
