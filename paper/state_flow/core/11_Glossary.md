# 11 Glossary

- **DSSF**：Deep State Space Flow，物理可审计解耦生成框架
- **Skeleton**：机理骨架（冲击节律/特征频率/趋势）
- **Texture**：统计纹理残差（宽带噪声/非高斯扰动）
- **FM (Flow Matching)**：回归向量场的 simulation-free 训练范式
- **RF (Rectified Flow)**：更直的 transport ODE，少步数采样
- **ECS**：事件一致性（A 层可证伪）
- **RDS**：共振漂移一致性（B 层可证伪）
- **SAS**：传感伪影一致性（C 层可证伪）
- **PCS**：物理一致性（特征频率能量占比）
- **FVD**：Fréchet Vibration Distance（深特征分布距离）
